# tcc-tesouro-ipca-deep-learning
Repositório oficial do TCC em Sistemas de Informação (UNIFESSPA). Benchmarking de arquiteturas de Deep Learning (LSTM, GRU e Transformers) sob Validação em Janela Deslizante (Walk-Forward), filtro estatístico de quartis (Sinal Combinado) e Backtesting fiduciário na marcação a mercado do Tesouro IPCA+ 2035 (NTN-B Principal).
